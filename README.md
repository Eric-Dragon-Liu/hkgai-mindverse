# Mindverse 多智能体执行系统

本仓库只做题目一：可恢复的多 Agent 运行系统。示例业务是 **B1 订单售后退款**。

## 启动

需要 Node.js 22.18+ 与 npm。

```sh
cd challenge-01-multi-agent
npm install
npm run dev
```

打开 http://localhost:3061。

```sh
npm test
npm run typecheck
npm run build
```

## 业务 B1

五个角色按依赖交接：受理完成后，长期记忆与政策检索并行；方案等待两边的结果；退款执行必须拿到限定订单和金额的审批。

| 步骤 | 角色 | 交接 |
| --- | --- | --- |
| 1 | 受理 | 写下订单、诉求和需求版本 |
| 2 | 长期记忆 | 只读该客户的历史，不混入制度文档 |
| 3 | 政策检索 | 检索售后制度，带来源和版本 |
| 4 | 方案 | 超限则冲突阻塞，不进入退款 |
| 5 | 退款执行 | 模拟退款；改需求后旧审批作废；同一笔不执行两次 |
